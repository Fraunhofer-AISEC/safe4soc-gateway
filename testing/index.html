    Testing the Endpoints¶

    Bruno Client (highly recommended)¶

    This section details how alerts can be sent through the gateways.

    The gateways can be tested using Bruno Client collection Get Bruno here: https://www.usebruno.com/ Once installed the testing collection located under ./api-testing which contains predefined REST API requests can be imported via File(top left) -> Open Collection.

    The predefined test cases can be launched via GUI or via CLI: 

    docker compose -f docker-compose-testing.yml run --rm bruno

    Curl Commands wih Variables¶

    The following sections show sample usages of the API using curl and command-line only.

    set your variables either using .env file or directly using these commands: 

    PROTOCOL="https"        #http|https
URL="localhost:10080"   #gateway-sender:10080 | localhost:10080
TOPIC="alerts"
