    Compilation¶

    The project is configured for the IDE Intellij Community Edition. The project uses Spring Boot, however it is compiled using GraalVM to produce an executable with faster startup times and less memory footprint during execution.

    Requirements¶

    To create the image, run the following gradlew build command. For installation instructions please see - Docker and docker-compose must be installed beforehand - Install GraalVM https://www.graalvm.org/latest/getting-started/ (NOTE: GraalVM 21.0.2 is working. GraalVM 25+ is not working!) - Install gcc glibc-devel zlib-devel etc. https://www.graalvm.org/latest/reference-manual/native-image/

    GraalVM Installation Via SDKMAN (a simplified option)¶

    Install SDKMAN. 

    curl -s "https://get.sdkman.io" | bash
source ~/.sdkman/bin/sdkman-init.sh
    Download and switch to GraalVM. 
    sdk install java 21.0.2-graalce
sdk use java 21.0.2-graalce

    Verify¶

    java -version
echo $GRAALVM_HOME 
echo $JAVA_HOME
    should show: GraalVM CE 21.x.x and both variables need to show to the installed GraalVM directory on your machine. If not you need to configure your local Java setup. Please note, do not use Graal VM 25 or above as it is not compatible with the Java-version used.

    Building Instructions Using Docker¶

    In main project's path run 

    ./gradlew clean nativeCompile

    Building Instructions Using IntelliJ IDEA¶

    The project can be opened using IntelliJ IDEA and the Spring Boot application can be launched and debugged directly using the run configuration profiles stored in folder ".run" in the project's root directory. One profile is used for the sender role and one for the receiver role.

    If natively launched within IntelliJ's execution, the behavior is the same as for the build using GraalVM, however, the startup time is slower and debugging is simplified.
